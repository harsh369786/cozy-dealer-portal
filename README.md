# BackRest Dealer Hub

BackRest Dealer PWA — UI/UX Design Concept

Design a modern, premium, clean and extremely easy-to-use Progressive Web App (PWA) for BackRest, a mattress, pillow and cushion manufacturer.

The PWA is primarily designed for dealers and distributors to browse the product catalogue, place orders, track orders, participate in campaigns and earn/redeem reward points.

I will provide 3 BackRest logo variations as reference. Use these logos to create different visual themes/colour systems while maintaining the same brand identity. Do not alter or redesign the logo itself.

Target Users

The primary users are dealers/distributors who may:

- Have limited technical knowledge

- Prefer simple, obvious interfaces

- Primarily use Android smartphones

- Often use the application while working in a shop

- Need to complete tasks quickly

- May not be comfortable with complicated menus or technical terminology

Therefore, simplicity and clarity are more important than adding too many features.

The interface should feel premium and professional, but never complicated.

Overall Design Direction

Create a visual identity around:

Sleep • Reset • Perform

The product category is mattresses, pillows and cushions, so the UI should communicate:

- Comfort

- Trust

- Premium quality

- Relaxation

- Health/well-being

- Reliability

- Rewards and achievement

Use a minimal, spacious and modern layout with strong visual hierarchy.

Avoid:

- Overly complicated dashboards

- Excessive text

- Tiny buttons

- Dense tables on mobile

- Too many colours

- Complicated navigation

- Technical terminology

- Excessive animations

Use:

- Large touch-friendly buttons

- Clear icons

- Product imagery

- Cards

- Simple navigation

- Short labels

- Visual progress indicators

- Friendly micro-interactions

- Subtle animations

Design for Mobile First

The dealer-facing PWA should be designed mobile-first, primarily around a 360–430px smartphone viewport.

The interface should also adapt well to tablets and desktop screens.

Use a bottom navigation bar for the primary dealer experience.

Suggested navigation:

Home | Products | Orders | Rewards | More

Keep the most important actions accessible within 1–2 taps.

## Visual Theme — Warm Neutral

The prototype uses a **single Warm Neutral theme** — calm, premium, and welcoming.

Visual direction:

- Cream and warm white backgrounds
- Soft beige cards and surfaces
- Muted soft gold for CTAs, rewards, and progress
- Subtle taupe/brown for secondary text and borders
- Dark warm charcoal for primary text

The overall feeling is **Comfortable • Premium • Calm • Elegant • Trustworthy** — appropriate for a mattress and sleep-products brand, without a heavy black-and-gold luxury aesthetic.

Gold is used sparingly for primary CTAs, reward highlights, progress indicators, and success moments. The interface stays light, airy, and comfortable.

---

Animation & Interaction

Use subtle, premium animations, not excessive motion.

Examples:

- Smooth page transitions

- Product cards gently appearing

- Reward progress bar animating when opened

- Points counter animation

- Confetti/celebration when a reward is unlocked

- Button press feedback

- Order confirmation animation

- Smooth bottom navigation transitions

- Campaign progress animation

Animations should improve usability and create a feeling of achievement.

They should also work well on lower-end Android phones.

Accessibility & Usability

This is extremely important.

Design for users with limited technical knowledge.

Use:

- Large readable text

- Large buttons

- High contrast

- Simple icons

- Clear labels

- Minimal steps

- Familiar terminology

- Obvious CTAs

- No unnecessary technical language

Instead of:

use:

"Place Order"

Instead of:

"Order Fulfilment Status"

"Track Order"

---

Final Goal

The purpose of this prototype is to show the business owner what the future BackRest dealer application could look and feel like.

Prioritize:

Simple → Fast → Premium → Trustworthy → Rewarding

The dealer should be able to understand the app without training.

A dealer should be able to:

Open → Browse → Select Product → Choose Size → Enter Quantity → Place Order

with minimal effort.

The rewards system should motivate dealers to sell more, while the overall application should feel like a premium BackRest product rather than a complicated enterprise management system.

Create polished, realistic UI screens with realistic mattress/pillow product imagery, sample dealer data and believable content so the prototype looks ready for a business presentation.
